# Controle Autoral

O autor tem a palavra final sobre o mundo.

- **Fixações** com escopo explícito: campo, entidade, área e período. Um recálculo respeita as fixações ([[Simulação]]).
- **Origem de cada valor:** edição manual, importação ou cálculo. *Desconhecido*, *estimado* e *zero* são coisas diferentes.
- **Exceções do cenário** (território disputado, dado incompleto, situação excepcional) ficam guardadas com justificativa.
- A validação distingue uma **representação intencional** de uma geometria inválida ou de uma referência quebrada.
- Quando uma operação afeta relações existentes, a interface mostra os objetos envolvidos e deixa corrigir as referências.

Isso já guiou a [[Calibração dos Mapas]]: cada valor tem um grau de confiança (definido, medido, estimado, hipótese).
